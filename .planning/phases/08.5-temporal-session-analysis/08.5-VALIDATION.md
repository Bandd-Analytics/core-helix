## Sampling Rate

- **After every task commit:** Run quick command (Phase 8.5 unit tests)
- **After every plan wave:** Run full suite (catches cross-phase regressions; Phase 6/7/8/8.4 must stay green)
- **Before `/gsd:verify-work` 8.5:** Full suite must be green; cross-phase regression gate identical to Phase 8.4 closure
- **Max feedback latency:** 15 seconds for quick command (Phase 8.5 only); ~120 seconds for full suite
