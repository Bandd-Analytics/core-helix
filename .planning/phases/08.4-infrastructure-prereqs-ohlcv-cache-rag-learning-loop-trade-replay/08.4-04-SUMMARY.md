## Decisions Made

- **OFFSET 1 in `_maybe_log_param_diff` query**: Plan said "compare to last trade's params_json for same (symbol, strategy)". The `log_trade` step (1) inserts the current trade FIRST, so the most-recent row is the one we just wrote. `OFFSET 1` skips it to find the genuine previous trade. This is the only correct ordering — without it, the diff is always "current vs current" and never fires.
- **rag_signal_filter default literal flip vs. broader API change**: The plan flagged Warning 6 (default collection split risk) and asked for a one-line change. Honored by editing only `RAGSignalFilter.__init__`'s default; embed/score/index_trade path untouched. Phase 8 D-29 preservation contract holds — explicit callers (`RAGSignalFilter(collection="trade_memory")`) are unaffected.
- **backtest call-site refactor strategy**: rec dict already had `'strategy'` key (e.g., `'SWING'`, `'M15_SCALP'`). The new `on_trade_close` inside `_maybe_log_param_diff` reads `strategy_type` (matches SQLite column) or `type`. Solution: add `rec['strategy_type'] = 'SWING'` (or `'M15_SCALP'`) immediately before `on_trade_close(rec)`. The logger's existing INSERT uses `trade['type']` for `strategy_type`; the diff helper reads `strategy_type`-or-`type`; consistent.
- **Task 3b deferral over auto-approve**: Wine MT5 (IC Markets KE MT5 Terminal) IS running locally per `pgrep terminal64.exe`. The spawned executor cannot capture MT5 GUI screenshots, so the 8-screenshot evidence requirement cannot be self-satisfied. Pragmatic: copied .mq5 sources into the MT5 Indicators dir, documented deferral, left INFRA-04 Pending in REQUIREMENTS.md. Operator can complete the visual pass at convenience.
- **mempalace.yaml kept tracked despite init auto-gitignore**: `mempalace init` automatically appends `mempalace.yaml` to .gitignore (issue #185). Per D-20, the file documents the project's keyword taxonomy and SHOULD be tracked. Override the auto-gitignore with a comment block explaining the D-20 role; commit YAML as documentation.
