## Operator notes

The MT5 export workflow that worked (in case Plan 04 or later phases need it again):
1. Tools → Options → Charts → "Max bars in chart" = 100000 (one-time)
2. Per pair: Ctrl+U → double-click pair → "Bars" tab → Period + From/To dates → Request → Export Bars → save to `~/Desktop/{PAIR}_{TF}_*.csv`
3. Orchestrator picks up via `python3 -m V2.scripts.normalize_mt5_exports --src ~/Desktop --dest V2/data/`
