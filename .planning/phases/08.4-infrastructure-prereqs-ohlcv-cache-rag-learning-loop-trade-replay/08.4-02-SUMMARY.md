## Decisions Made

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| `pit.py` augmentation strictly additive | Phase 8 contract (D-25 UNBOUNDED disabled) is the riskiest break-axis. Conditional `if self._as_of is not None: _bump(±1)` keeps UNBOUNDED at depth=0 by construction. | 8/8 Phase 8 PitClock tests still PASS; pit.py grew 134→165 lines without removing or renaming any existing symbol |
| Lazy import of `fetch_range` inside `_auto_pull` | Breaks the cache.py↔update_cache.py module cycle (update_cache imports OHLCVCache; cache._auto_pull would import update_cache.fetch_range). Lazy = only the auto-pull code path needs scripts/ on sys.path. | cache.py imports cleanly without scripts/ on path; tested via `python -c "from v3_intelligence.cache import OHLCVCache"` succeeding |
| `_read_only` retry path is non-recursive | Avoids the auto-pull-loop pitfall: if broker returns nothing, the retry must NOT re-trigger _auto_pull. Separate `_read_only` method reads exactly once and returns whatever is in the cache (possibly empty). | Idempotent — second run with empty broker returns empty df instead of looping |
| Conftest fixture bridge instead of renaming conftest_infra.py | Plan 01 deliberately chose conftest_infra.py to keep Phase 8.4 fixtures visually separate. Renaming would lose that intent. Re-export pattern preserves separation while satisfying pytest's "only conftest.py is auto-discovered" rule. | 8/8 cache.py unit tests turned GREEN at first invocation after the 11-line bridge edit |
| Title-case rename map on lowercase column names only | DB schema uses lowercase (open/high/low/close/volume); test contract uses Title-case. Rename map is one-way: lowercase keys → Title-case values. Empty DataFrame fast-path returns early before rename. | `test_get_bars_returns_titlecase_columns` GREEN; `test_round_trip_upsert_then_get` (slow, will GREEN under DB URL) verifies end-to-end |
