    **Calculation logic step-by-step:**
    1. On `OnInit` and on each new D1 bar: compute `ADR = mean(D1_high[i] - D1_low[i])` for i = 1..LookbackDays (skipping today's incomplete bar).
    2. Read `today_open = iOpen(symbol, PERIOD_D1, 0)`.
    3. Compute `ADR_high = today_open + ADR / 2`, `ADR_low = today_open - ADR / 2`, `ADR_mid = today_open`.
    4. Create or update `OBJ_HLINE` objects at the three price levels.
    5. Refresh trigger: D1 bar change OR a periodic timer (`EventSetTimer(60)` in MQ5 idiom — see ADR_Levels.mq5 line 35).
    6. On `OnDeinit`: delete all objects with `ObjectPrefix`.

    Bar-iteration model: not every-tick (would thrash); D1-bar-change OR 60-second timer.

    **Pseudocode** (≥ 10 lines, language-neutral):
    ```
    function on_init():
        compute_adr_lines()
        set_timer(60)

    function compute_adr_lines():
        sum_range = 0
        for i in 1..LookbackDays:
            sum_range += daily_high(i) - daily_low(i)
        ADR = sum_range / LookbackDays
        today_open = daily_open(0)

        adr_high = today_open + ADR / 2
        adr_low  = today_open - ADR / 2
        adr_mid  = today_open

        upsert_hline(ObjectPrefix + "high", adr_high, HighColor, LineStyle, LineWidth)
        upsert_hline(ObjectPrefix + "low",  adr_low,  LowColor,  LineStyle, LineWidth)
        if ShowMidline:
            upsert_hline(ObjectPrefix + "mid", adr_mid, MidColor, LineStyle, LineWidth)
        if ShowLabel:
            adr_pips = points_to_pips(ADR)
            upsert_label(ObjectPrefix + "lbl", "ADR(" + LookbackDays + "): " + adr_pips + " pips")

    function on_timer():
        if d1_bar_changed_since_last_call():
            compute_adr_lines()

    function on_deinit():
        delete_objects_with_prefix(ObjectPrefix)
    ```
