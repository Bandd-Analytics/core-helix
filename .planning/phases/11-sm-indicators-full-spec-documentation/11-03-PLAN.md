    **Purpose:** Two paragraphs.
    Paragraph 1: TDI (Traders Dynamic Index) was created by Dean Malone and adopted by Steve Mauro as the SOLE confirmation indicator for MMM strategies. It combines RSI, Bollinger Bands, and moving averages into a single subwindow display showing momentum, volatility, and trend in one view. Cite the MMM TDI Tradestation PDF as the canonical source; cite MMM Book pp. 45-46 for MMM-specific usage patterns (Shark Fin, Blood in the Water, VB Squeeze).
    Paragraph 2: TDI is composed of 5 lines and 3 levels:
    - **Green line (RSI Price Line / RSI PL)** — 2-period SMA of the underlying RSI
    - **Red line (Trade Signal Line / TSL)** — 7-period SMA of the underlying RSI; lagging signal
    - **Yellow line (Market Base Line / MBL)** — 34-period SMA of the underlying RSI; trend midline
    - **Blue lines (Volatility Bands / VB upper + VB lower)** — Bollinger Bands on the MBL with period 34 and StdDev 1.6185
    - **Levels** — horizontal dashed lines at 32 (Selling Exhaustion / oversold), 50 (Sentiment midpoint), 68 (Buying Exhaustion / overbought)

    **Outputs:**
    - Indicator buffers: 5 buffers — `RSI_PL[]` (Green), `TSL[]` (Red), `MBL[]` (Yellow), `VB_upper[]`, `VB_lower[]` — exposed via standard MQL4 buffer indexing so EAs can `iCustom("SM_TDI", ..., buffer_index, shift)` to read live values.
    - Chart objects: None directly; the lines are drawn via indicator buffers in a SUBWINDOW.
    - Alerts: Three alert types (see Calculation logic).

    **Calculation logic step-by-step:**
    1. Compute base RSI: `RSI_raw[i] = iRSI(symbol, period, RSI_Period, RSI_Price, i)` for i = rates_total - 1 .. 0.
    2. **Green line (RSI PL):** `RSI_PL[i] = SMA(RSI_raw, RSI_Price_Line, i)` — 2-period SMA of the RSI series.
    3. **Red line (TSL):** `TSL[i] = SMA(RSI_raw, Trade_Signal_Line, i)` — 7-period SMA.
    4. **Yellow line (MBL):** `MBL[i] = SMA(RSI_raw, Market_Base_Line, i)` — 34-period SMA.
    5. **Blue Volatility Bands:** Compute standard deviation of RSI_raw over Volatility_Band period: `sigma = StdDev(RSI_raw, Volatility_Band, i)`. Then `VB_upper[i] = MBL[i] + StdDev * sigma`, `VB_lower[i] = MBL[i] - StdDev * sigma`.
    6. Draw three horizontal level lines at 32, 50, 68 in the subwindow.
    7. **Alert detection (every new bar close):**
       - **TDI Signal Cross:** `RSI_PL[1] > TSL[1] AND RSI_PL[2] <= TSL[2]` → bullish signal (or inverse for bearish).
       - **MBL Cross:** `RSI_PL[1] crosses MBL[1] AND RSI_PL[1] > TSL[1] AND high[1] > avg(high[2..N])` (price confirmation per MMM TDI PDF p. 16).
       - **TDI Hook:** Bullish hook: `RSI_PL near 32 AND RSI_PL[1] > VB_lower[1] AND RSI_PL[2] <= VB_lower[2]`. Bearish hook: `RSI_PL near 68 AND RSI_PL[1] < VB_upper[1] AND RSI_PL[2] >= VB_upper[2]`.
    8. Bar-iteration: `prev_calculated` optimization — recompute only new bars. Alerts fire on bar-close transition (i = 1 in MT4 indexing).

    **Pseudocode** (≥ 10 lines, language-neutral):
    ```
    function on_calculate(rates_total, prev_calculated):
        start = max(prev_calculated - 1, max(RSI_Period, Market_Base_Line) + 1)
        for i in start..rates_total - 1:
            rsi_raw[i] = rsi(close, RSI_Period, i)

        for i in start..rates_total - 1:
            rsi_pl[i] = sma(rsi_raw, RSI_Price_Line, i)        # Green
            tsl[i]    = sma(rsi_raw, Trade_Signal_Line, i)     # Red
            mbl[i]    = sma(rsi_raw, Market_Base_Line, i)      # Yellow
            sigma     = stddev(rsi_raw, Volatility_Band, i)
            vb_upper[i] = mbl[i] + StdDev * sigma              # Blue upper
            vb_lower[i] = mbl[i] - StdDev * sigma              # Blue lower

        last = rates_total - 2
        prev = rates_total - 3

        if EnableSignalCrossAlert:
            if rsi_pl[last] > tsl[last] and rsi_pl[prev] <= tsl[prev]:
                fire_alert("TDI Signal Cross BULLISH")
            elif rsi_pl[last] < tsl[last] and rsi_pl[prev] >= tsl[prev]:
                fire_alert("TDI Signal Cross BEARISH")

        if EnableMBLCrossAlert:
            if rsi_pl[last] > mbl[last] and rsi_pl[prev] <= mbl[prev]
               and rsi_pl[last] > tsl[last] and high[last] > avg_high(2, 6):
                fire_alert("TDI MBL Cross BULLISH (Blood in the Water)")

        if EnableHookAlert:
            if rsi_pl[last] < 40 and rsi_pl[last] > vb_lower[last]
               and rsi_pl[prev] <= vb_lower[prev]:
                fire_alert("TDI Hook BULLISH (counter-trend)")
            elif rsi_pl[last] > 60 and rsi_pl[last] < vb_upper[last]
                 and rsi_pl[prev] >= vb_upper[prev]:
                fire_alert("TDI Hook BEARISH")
    ```

       - For each OBJ_TREND `name`: read `time1, price1, time2, price2`; compute slope = `(price2 - price1) / (time2 - time1)` (zero-protected); intercept-from-time1: `price_at_now = price1 + slope * (current_time - time1)`.

    ```
    state last_alert_time : map<trendline_name, datetime> = {}
    state prev_side       : map<trendline_name, int>     = {}

    function on_tick():
        now = current_time()
        bid = current_bid()
        for i in 0..total_chart_objects() - 1:
            obj_name = chart_object_name(i)
            if object_type(obj_name) != OBJ_TREND: continue
            if OnlyMonitorPrefix != "" and not obj_name.startswith(OnlyMonitorPrefix): continue

            t1 = object_get_time(obj_name, 0); p1 = object_get_price(obj_name, 0)
            t2 = object_get_time(obj_name, 1); p2 = object_get_price(obj_name, 1)
            if t2 == t1: continue                        # vertical trendline, skip
            slope = (p2 - p1) / (t2 - t1)
            projected = p1 + slope * (now - t1)
            dist_pips = abs(bid - projected) / pip_unit()
            current_side = sign(bid - projected)

            if AlertOnTouch and dist_pips <= TouchPips:
                if now - last_alert_time.get(obj_name, 0) >= RepeatAlertSeconds:
                    fire_alert("TL TOUCH " + obj_name + " " + format(bid))
                    last_alert_time[obj_name] = now
            if AlertOnCross and obj_name in prev_side and prev_side[obj_name] != 0 \
               and current_side != 0 and current_side != prev_side[obj_name]:
                fire_alert("TL CROSS " + obj_name + " " + format(bid))
                last_alert_time[obj_name] = now

            prev_side[obj_name] = current_side

            if DrawTouchMarker and dist_pips <= TouchPips:
                draw_marker(obj_name + "_touch_" + format(now), now, bid, TouchMarkerColor)
    ```
