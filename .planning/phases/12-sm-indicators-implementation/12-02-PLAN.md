ATR (Wilder smoothing) — same recipe used in Pitfall 4 RSI from Plan 12-03 SM_TDI:
```python
def _wilder_atr(high: pd.Series, low: pd.Series, close: pd.Series, period: int) -> pd.Series:
    """ATR with Wilder's smoothing — matches MT4/MT5 iATR() output."""
    tr1 = high - low
    tr2 = (high - close.shift(1)).abs()
    tr3 = (low - close.shift(1)).abs()
    tr = pd.concat([tr1, tr2, tr3], axis=1).max(axis=1)
    return tr.ewm(alpha=1.0 / period, adjust=False).mean()
```
